# Bob

Say **“Hey Bob”**. A voice assistant with feelings, by **Bubbles Aro** — powered by Bubbles.

**Website:** https://abhiramupadrashta.github.io/Bob/ · **Web app:** https://abhiramupadrashta.github.io/Bob/app/
**Download:** [latest release](https://github.com/AbhiramUpadrashta/Bob/releases/latest) — Android (Bob.apk), Mac (Bob-mac.zip), Windows (Bob-Setup.exe)

Bob calls people (asks for the name or number), sends messages, sets alarms, timers and reminders, opens apps,
plays music, gives directions, answers questions, controls volume, flashlight, screenshots and more. Send him
away without giving him work and he leaves crying; thank him and he waves goodbye.

This repository only builds and publishes the finished apps and website. The source code is private.
